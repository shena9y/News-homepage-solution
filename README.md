# 📰 News Homepage

My solution to the [News Homepage challenge](https://www.frontendmentor.io/challenges/news-homepage-H6SWTa1MFl) on [Frontend Mentor](https://www.frontendmentor.io) — a modern, responsive news landing page featuring a hero article, a "New" articles sidebar, and a numbered popular-articles section.

## ✨ Features

- 📱 **Responsive layout** — adaptive grid for desktop and mobile
- 🍔 **Animated mobile menu** — hamburger icon toggles the navigation, swaps open/close icons, and blurs the background content while open
- 🗞️ Hero section with featured "Web 3.0" article
- 🆕 Sidebar listing the latest "New" posts
- 🔢 Numbered top-articles row (Retro PCs, Top Laptops, Gaming Growth)

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid & Flexbox)
- Vanilla JavaScript (menu toggle & blur effect)

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/shena9y/News-homepage-solution.git
   ```
2. Open `index.html` in your browser — no build step required.
